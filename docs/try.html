Your file

A text or CSV file with q in the first column and intensity in the second. Other columns, such as errors, are ignored, and so are lines that do not start with a number. Choose the unit of q. The page guesses it from the largest value. The example is a curve from the simulator itself, with noise added as in a measurement, so its true parameters are known. The example file shows the format.

Normalisation and window

Measured intensities are in arbitrary units, so your curve is shifted to the height of the simulated curve and only the shape is compared. By default the shift is one scale factor fitted over the window, as in most fitting programs. The alternatives give both curves the same integral of q²I over the window, or make them equal at one q. Only points inside the window are used, for the normalisation and for the difference. The window can be at most 0.01–0.30 Å−1, the range of the simulations. For its measured curves the paper used 0.05–0.30 Å−1. The Kratky view plots I·q² against q, which shows the shape at middle and high q more clearly. The difference is always computed in log intensity.

Where the simulated curves come from

The curves are computed by a surrogate, a small neural network (0.24 MB) trained on the 131,072 simulated structures that were used to train the network in the paper. It reproduces the simulator to about 2 % in intensity, which is about how much the simulator itself varies between random seeds. The network gives three parts of the curve for each structure, and the densities combine them exactly, so the densities are not learned. Because the network runs in your browser, the curve updates as you move a slider.

The structure

The picture is a cross-section built by the same simulator that made the training data, running in your browser. Each time you let go of a slider it builds a new random structure with those settings, and the button builds another with the same settings. The pixels are 0.36 nm, as in the paper. The default piece is 186 nm wide. The paper used 744 nm, which takes a second or two. The picture only shows the structure. The curve in the plot comes from the surrogate, which gives the average over many structures. The densities do not change the structure, only the colours.

What a match means

This page is meant for exploration. The simulator describes one kind of structure: cellulose fibrils, a matrix, and an interstitial phase between them. A close match does not show that your sample has this structure, and quite different settings can match a curve equally well. The cellulose page shows how much a single curve leaves open.
