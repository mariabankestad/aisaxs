How the method works

A measurement, for us a SAXS curve, rarely pins down one set of parameters. So we do not ask for one answer. A neural network generates the combinations that fit: the posterior. If we already know something about one parameter, fewer combinations remain. One trained network handles all these cases.

How the network learns this

All it needs is a simulator. Which parameters are hidden changes from one example to the next, so the same network learns to answer whatever is hidden.

  1. SimulateThe simulator draws parameters and makes their measurement.
  2. Make a training exampleHide some parameters and keep the others. Replace the hidden ones by a point between random noise and their true values.
  3. Train the networkAsk for the direction from the noise to the true values, and correct the network when it is wrong.
Technical details

One training example with four parameters:

θ₁0.82unknowna point between noise and 0.82the direction from the noise to 0.82
θ₂0.15unknowna point between noise and 0.15the direction from the noise to 0.15
θ₃0.55known roughly, ± 0.10.61, the true value with a random error, and 0.1nothing
θ₄0.30known exactly0.30nothing

The roughly known parameter is shown with a random error on purpose, and its true value is never shown. This is why the network learns to treat such a value as a hint and not as the truth.

# training
repeat many times:
    θ, x  = simulator()                  # parameters and their measurement
    roles = random role for each parameter
    ε     = noise,   t = random time between 0 and 1
    z     = (1 − t)·ε + t·θ              # a point between noise and the truth
    v     = network(z, known values, roles, t, x)
    loss  = (v − (θ − ε))²               # on the unknown parameters only

# using the trained network
s = encoder(x)                           # the measurement, encoded once
z = noise for the unknown parameters
for t from 0 to 1 in small steps:
    v = network(z, known values, roles, t, s)
    z = z + step · v                     # only the unknown parameters move
return z                                 # samples of the posterior

The method is called flow matching, here with masking: the hidden parameters are the masked ones. The network answers the question it is given. Whether a known value agrees with the measurement is a separate check, made against the samples from the measurement alone; the cellulose page shows it.
