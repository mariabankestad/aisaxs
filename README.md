# AI-SAXS

Project page: https://mariabankestad.github.io/aisaxs/

**Looking for the code from the npj paper on lipid nanoparticles?** It is in
[aisaxs-poly](https://github.com/mariabankestad/aisaxs-poly) and archived at
Zenodo ([10.5281/zenodo.20338599](https://doi.org/10.5281/zenodo.20338599)).
The exact version from the paper is also kept here as release
[v1.0.0](https://github.com/mariabankestad/aisaxs/tree/v1.0.0).

This repository holds the AI-SAXS project page. It collects our work on
machine learning for small-angle X-ray scattering (SAXS) and lets you try
the methods in the browser. The pages are in `docs/`.
